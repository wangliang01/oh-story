# story-premise · 动笔前三件事

动笔前的三块基石：一句话卖点、目标读者、故事基调。这三件事不定死，后面写得越多越乱。

## 何时使用
- 用户要启动新故事构思，还没有卖点/读者/基调
- story-bible.md 的第一、二节还是 draft

## 篇幅模式
- **短篇/微小说**：一句话简介必须能在 10 秒内向陌生人讲清（短篇容错率低，卖点含糊直接劝退）；基调收敛为**单一主导情绪**（一个词：寒、痒、痛、爽），不要混搭；读者定位改为"读完后 5 分钟内的情绪余味"——短篇的爽点是一次性冲击，不是长期追更。
- **长篇**：按主流程执行；基调可以复合但必须自洽（如"暗黑但爽"），允许铺垫空间。
- **中篇**：介于两者之间，基调允许 1 个次级情绪陪衬。

## 输入
- story-bible.md（若已存在）；用户的题材或初步想法

## 流程

### 第 1 步 · 一句话卖点
按万能公式提问，一次一问，最多 5 问：
**谁 + 在什么处境下 + 为了什么 + 做了什么 + 付出什么代价 + 得到什么结果**

引导问题与示例：
- 主角是谁、处于什么处境？（示例：被家族抛弃的庶女）
- 他/她想要什么？（示例：活下去并复仇）
- 准备怎么做？（示例：步步为营搅动朝堂）
- 要付出什么代价？（示例：众叛亲离、如履薄冰）
- 最终得到什么？（示例：以女子之身权倾天下）

用户答完 → 帮用户整合出 **2~3 个一句话版本**，让用户选一个或微调。写不出一句话简介，说明构思还没到位，继续追问，不要放过。

### 第 2 步 · 读者定位
按题材给出读者爽点清单，让用户确认或修正：
- 甜文：情绪稳定、糖分充足、误会少、打脸快
- 悬疑：逻辑在线、伏笔密集、反转合理
- 现实向：真实、扎心、有共鸣、有出口
- 玄幻：升级清晰、爽点密集、世界观自洽

明确"写给谁看，就按谁的爽点构思"。不考虑读者的小说，大概率只能自嗨。

### 第 3 步 · 故事基调
三组二选一/多选，**一旦定死中途不变**：
- 爽 / 虐 / 甜 / 烧脑 / 治愈 / 压抑
- 快节奏 / 慢热
- 轻松向 / 暗黑向

提醒用户：甜文突然虐到窒息、悬疑突然搞笑崩坏，读者必跑。

## 题材专项：现实情感（盐选短篇）
写现实情感/生活向短篇时，卖点公式追加一条（从 14 篇签约范文提取）：
- **叙述者人设即卖点**：一句话里除了事件，还要带上叙述者的性格（"一个被绿的丈夫冷静地帮老婆和情人撮合" > "一个丈夫发现老婆出轨"）。性格决定口吻，口吻决定辨识度。
- 示例：克制蓄怒型（"我女朋友租了一个她绝对租不起的房子，还和房东眉来眼去"）、幽默活泼型（"妈的，揩我老婆油！"）、自嘲打脸型（开头嚣张结尾认栽）。
- 基调默认：现实向短篇的情绪是"压抑中的爆发"，快节奏、口语化、短句。

### 悬疑（盐选短篇）· 卖点公式（一次校准）
一句话里必须带上"**说不通的东西**"——异常细节或反常逻辑，而不是题材标签（"凶杀案"太平庸，"每一步都用恰巧解释，就像赶着去送死"才是卖点）。示例："乱葬岗扒死人衣服，却摸到一幅带着体温的画卷"。基调：冷、紧、层层逼近。

### 言情（盐选短篇）· 卖点公式（一次校准）
一句话里必须带上"**关系错位**"——第一段就建立不对的关系。示例："租了个女友回家过年，来的却是我的女上司"；"失忆后，她说我们只是普通朋友"。基调：克制、暧昧、暗涌，读者要的是关系反转的爽，不是直白的甜。

## 平台卖点公式（一次校准：盐选调查）
- **盐选（男频）**：一句话 = **事件 + 憋屈处境 + 反杀路径 + 叙述者性格**；导语版 15~25 字（数据背书），带数字/反差（悬念型/反差型/极端事件型），具象化禁抽象。
  - 示例："我女朋友租了一个她绝对租不起的房子，还和房东眉来眼去。"（房租背后）
  - 各题材导语公式/反转母题/易踩坑 → 先查 `story-platform/references/genre-baselines.md`，再动笔。
  - **定平台/选题材前**：先查 `story-platform/references/market-signals.md`（2026-08-14 重核：盐言悬疑犯罪含复仇向 35% 第一 + 中式志怪/民俗新趋势 + 男频机会；番茄男频在读榜 TOP6 + 规则怪谈黑马 + 短剧变现）。题材与平台不匹配直接拦下改方向。
- **番茄（男频）**：一句话 = **金手指 + 爽点类型（升级/打脸/逆袭）+ 世界（都市/玄幻/系统）**；卖点是"开局即爽"，不是"结局反转"。
  - 示例："被全宗门退婚的废柴，觉醒签到系统，每日签到白拿上古神通。"

## 输出
story-bible.md 第一、二节内容，更新 status。

## 完成标准
三件事都有明确答案：一句话简介（能向陌生人 10 秒讲清）、读者是谁（能说清他们的爽点）、基调是什么（一组形容词，不可自相矛盾）。
