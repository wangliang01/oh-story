# 知识底料：动笔前三件事

## 一、动笔前先想清楚三件事，否则写得越多越乱

很多人动笔就写第一章，结果写到中间逻辑崩盘、人物跑偏、情节失控。真正成熟的作者，动笔前一定先锁定三件事：

### 1. 一句话说清你的故事（核心卖点）
写不出一句话简介，说明你根本没构思明白。

**万能公式**：谁 + 在什么处境下 + 为了什么 + 做了什么 + 付出什么代价 + 得到什么结果

举例：
- 一个被家族抛弃的庶女，为了活下去并复仇，步步为营搅动朝堂，最终以女子之身权倾天下。
- 一个普通社畜意外获得回溯时间的能力，却每次只能回到前一天，他必须在有限次数里阻止一场连环杀人案。

一句话立住，全书就不会歪。

### 2. 明确你的读者是谁
- 写甜文：读者要情绪稳定、糖分充足、误会少、打脸快
- 写悬疑：读者要逻辑在线、伏笔密集、反转合理
- 写现实向：读者要真实、扎心、有共鸣、有出口
- 写玄幻：读者要升级清晰、爽点密集、世界观自洽

写给谁看，就按谁的爽点去构思。不考虑读者的小说，大概率只能自嗨。

### 3. 定好故事基调
- 爽 / 虐 / 甜 / 烧脑 / 治愈 / 压抑
- 快节奏 / 慢热
- 轻松向 / 暗黑向

基调一旦定死，中途不要乱变。甜文突然虐到窒息，悬疑突然搞笑崩坏，读者必跑。
