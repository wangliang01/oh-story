# story-plot · 情节设计

所有好看的故事都藏在三层结构里。本 skill 负责把"情节"从灵感变成可执行的骨架。

## 何时使用
- 用户要搭情节/大纲/结构
- story-bible.md"情节"节是 draft 或评审不通过

## 输入
- story-bible.md（卖点、人物已定的前提下搭结构；冲突要服务于人物）

## 篇幅与平台模式（档位参数来自 story-platform）
- **微小说（<3k）**：单弧光，篇幅比例节奏——开头 10% 炸点 / 中段 70% 单峰冲突（一次"想要→得不到→只能拼→付出代价"，不循环）/ 结尾 10% 余韵；"每章钩子"改为"**每个段落结尾留悬念**"；不写副线。
- **盐选短篇（8k~3w，默认）**：**每节 500~800 字一个反转单元**；开篇即冲突（第一章出现核心事件）；三章必反转；每 2 章至少一个"目标+阻碍"冲突；单主弧光 + 最多 1 条轻副线；每节末留钩。
- **中篇（3w~10w）**：主流程 + 1 条副线，起伏密度减半（每 20~30 章一个大起伏）。
- **长篇（10w+，番茄）**：按番茄节奏——**黄金三章**（首章惨+金手指+首爽点/二章验证/三章打脸升级）、每章 2000~3000 字、每章结尾钩子、每 3~5 章小爽点；升级循环（每 10 章小起伏/每 50 章大起伏）。
  - 悬疑/困局类短篇硬规则（一次校准）：**必须有规则层面的翻转**（规则本身被打破/反转，如"旅馆其实在替主角保存声音"），不能只有心理层面的翻转（"我意识到我的愧疚"）——后者读者已经预测到。
  - 现实情感短篇硬规则（一次校准，源自 14 篇签约范文）：① 第一句必须是画面+冲突（"去健身房接老婆，却看见她跟一个男人姿势暧昧"），禁止背景介绍开头；② 情绪峰值前置——生死/背叛类峰值出现在开头 1/5 内，不慢热；③ 不写情绪词，写身体反应与动作（"我喇叭不敢停"而非"我很怕"）；④ 结尾必须有一句定性/余味的话（金句如"坏人接受惩罚"或反差如"嗯，真乖！"），不能"讲完就停"；⑤ 节极短、短句密集、对话推进。
  - 悬疑短篇硬规则（一次校准，源自 12 篇签约范文）：① 第一段必须出现"说不通的东西"（异常物件/反常逻辑/诡异事件），禁止从解释世界观开始；② 悬疑感来自解释不通的巧合与细节，不是吓人；③ 结构=层层揭秘，每节结尾留小钩；④ 结尾必须回收全部钩子，且真相"比猜测更黑"；⑤ **首尾呼应**——结尾重复开头钩子句但语义翻转（"就跟赶着去送死一样！"）。
  - 言情短篇硬规则（一次校准，源自 4 篇签约范文）：① 第一段必须建立"不对的关系"（身份错位/认知错位/选择错位）；② 核心爽点=关系反转（推翻读者开局预期），不是虐；③ 情绪克制——不写"我很爱她"，写一个动作；④ 结尾呼应开局错位并修正落地（"从我的上司，变成我的妻子"）。
- **长篇**：按主流程执行（每3~5章爽点/每10章起伏/每50章大起伏/每章钩子）。
- **中篇**：主流程，但只保留 1 条副线，起伏密度减半（每 20~30 章一个大起伏）。

## 流程

### 第 1 步 · 三层结构
**第一层 开端——破局**：日常状态 → 意外闯入（系统激活/亲人被害/被退婚/遭遇凶案/穿越）→ 被迫上路。原则：前三章必须出冲突、出目标、出人设。
- 问：开局那个"意外"是什么？主角被逼到哪条路上？

**第二层 发展——升级打怪（核心爽点区）**：小高潮循环——遇到问题 → 陷入困境 → 寻找方法 → 反转逆袭 → 获得奖励/成长/关系推进。每 10 章一个小起伏，每 50 章一个大起伏。不堆日常、不水字数。
- 问：这个循环的第一轮是什么？中期大反转（颠覆认知的那一下）在哪里？

**第三层 结局——收束**：最终 BOSS 战/最终抉择/最终真相 → 主角成长弧光完成 → 所有重要人物归宿交代 → 核心主题落地。烂尾 90% 因为前期伏笔不收、中期逻辑不闭环。
- 问：结尾要收哪些伏笔？主题落地的最后一幕是什么？

### 第 2 步 · 核心冲突
四类冲突，至少选两类为主：
- 人与自我（内心挣扎/恐惧/欲望/道德抉择）——最显深度
- 人与人（恩怨/竞争/背叛/爱情/对立）——最常见
- 人与环境（生存危机/规则压迫/时代困境）——网文常用
- 人与命运（预言/诅咒/轮回/宿命）——拉高格局

冲突制造公式（让用户按公式填）：**想要 → 得不到 → 有人拦 → 只能拼 → 付出代价**
- 甜文示例：想在一起 → 现实不允许 → 误会/家族/身份阻拦 → 主动破冰 → 牺牲与选择
- 悬疑示例：想查真相 → 证据被毁 → 凶手布局 → 逆向推理 → 接近死亡

冲突越极致，故事越上头。

### 第 3 步 · 节奏规划
- **爽点密度**：网文每 3~5 章一个小爽点；言情每 10 章一次感情升温；悬疑每章留一个钩子。
- **松紧搭配**：紧张后放轻松日常；感情爆发后给缓冲；大战后给收获成长。一直紧绷读者累，一直松弛读者跑。
- **钩子意识**：每章结尾必须留钩子——突然出现的人/突然反转的真相/突然到来的危机/一句让人震惊的话。无钩子，不追更。

黄金模板 8 步作为结构主轴参考（见 references/plot-notes.md）。

### 第 4 步 · 情绪曲线设计（一次校准：盐选调查 + 用户反馈）
- **必须有情绪出口**：基调再压抑，也要设计至少一个"爽/解气/暖/释然"的释放点。禁止全程压抑——用户反馈：压抑无出口 = 阅读不适（《岳母的存折》反例）。
- 起伏比例 ≈ **7:2:1**（主情绪:次情绪:反转情绪）；盐选节奏下每 500~800 字一个情绪点；番茄按 8:2 爽:虐。
- 自查：把每个情绪点在稿子上标出来，若某段 800 字以上无情绪变化，删或改。

### 第 5 步 · 具象化（真实感，一次校准）
- 禁抽象词（"很贵/很久/大城市"→"月租两千的三里屯一居室"）；用具体金额/地名/年份/品牌/职业黑话。
- 行为细节代替形容词（"我喇叭不敢停"≠"我很怕"）；动词占比 >60%。
- 每章 2~3 个具象细节锚点。自查：把抽象形容词全部划掉，句子还能成立吗？成立 = 具象达标。

## 输出
story-bible.md"情节"节（三层结构 + 核心冲突 + 节奏规划），更新 status。

## 完成标准
三层结构每层都有具体内容（不是空话）；冲突按公式完整填出；节奏有明确的爽点密度和每章钩子示例。无【待定】。
