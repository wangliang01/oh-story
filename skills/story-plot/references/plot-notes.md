# 知识底料：情节 / 冲突 / 节奏

## 三、情节构思：用"三层结构"搭骨架，永远不崩

不管长篇短篇，所有好看的故事，都藏在这套结构里。

**第一层：开端——破局**
- 主角日常状态
- 意外事件闯入（系统激活、亲人被害、被退婚、遭遇凶案、穿越）
- 主角被迫踏上新道路
- 原则：前三章必须出冲突、出目标、出人设。

**第二层：发展——升级打怪（核心爽点区）**
用"小高潮 + 小高潮 + 大高潮"循环：
- 遇到问题 → 陷入困境 → 寻找方法 → 反转逆袭 → 获得奖励/成长/关系推进
- 每10章一个小起伏，每50章一个大起伏。
- 不堆砌日常，不强行水字数。

**第三层：结局——收束所有伏笔**
- 最终BOSS战/最终抉择/最终真相
- 主角完成成长弧光
- 所有重要人物归宿交代清楚
- 核心主题落地
- 烂尾，90%是因为前期伏笔不收，中期逻辑不闭环。

## 四、冲突构思：没有冲突，就没有小说

读者追更，追的不是剧情，是冲突。你要学会主动制造冲突。

**四类核心冲突**
- 人与自我：内心挣扎、恐惧、欲望、道德抉择（最显深度）
- 人与人：恩怨、竞争、背叛、爱情、对立（最常见）
- 人与环境：生存危机、规则压迫、时代困境（网文常用）
- 人与命运：预言、诅咒、轮回、宿命（拉高格局）

**冲突制造公式**
想要 → 得不到 → 有人拦 → 只能拼 → 付出代价

- 想写甜文：想在一起 → 现实不允许 → 误会/家族/身份阻拦 → 主动破冰 → 牺牲与选择
- 想写悬疑：想查真相 → 证据被毁 → 凶手布局 → 逆向推理 → 接近死亡

冲突越极致，故事越上头。

## 五、节奏构思：决定读者能不能追下去

爆款小说，节奏永远是"张弛有度"。

**爽点密度**
- 网文：每3~5章一个小爽点
- 言情：每10章一次感情升温
- 悬疑：每章留一个钩子

**松紧搭配**
- 紧张剧情后 → 放一段轻松日常
- 感情爆发后 → 给一点缓冲空间
- 大战结束后 → 给一点收获与成长
- 一直紧绷读者累，一直松弛读者跑。

**钩子意识**
每一章结尾，必须留钩子：
- 突然出现的人
- 突然反转的真相
- 突然到来的危机
- 一句让人震惊的话
- 无钩子，不追更。

## 七、爆款小说的通用"黄金模板"，直接套用

1. 开篇炸点（危机/意外/反转）
2. 主角亮相（性格+能力+困境）
3. 目标确立（活下去/复仇/破案/相爱）
4. 连续小冲突（不断闯关）
5. 中期大反转（颠覆认知）
6. 人物成长（主角蜕变）
7. 最终高潮（决战/抉择/真相）
8. 结局闭环（情感+逻辑双满足）

照着这个结构构思，写出来的故事天然具备爆款潜质。
