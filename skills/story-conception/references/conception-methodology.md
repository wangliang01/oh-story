# 框架总览：方法论 → skill 映射

整套构思方法论共八大部分，映射关系如下：

| 方法论部分 | 负责 skill |
|---|---|
| 一、动笔前三件事（卖点/读者/基调） | story-premise |
| 二、人物构思（主角三要素/三类配角/反派三逻辑） | story-character |
| 三、三层结构（破局/升级/收束） | story-plot |
| 四、冲突构思（四类冲突/冲突公式） | story-plot |
| 五、节奏构思（爽点密度/松紧/钩子） | story-plot |
| 六、世界观与细节 | story-world |
| 七、黄金模板（8 步） | story-plot（结构参考）/ story-validate（评审轴） |
| 八、八大坑 | story-validate（评审轴 + 救场） |

## 核心原则
1. **先设计，再填充；先立骨，再填肉；先抓心，再讲故事。**
2. **评审优先**：用户带已有内容来 → 先评审（story-validate），再按评审结果补缺。
3. **按完成度推进**：story-bible.md 的 status 是唯一的事实来源，哪节 draft 补哪节。
4. **一句话立住，全书不歪**：卖点不定死，不动笔。

## 黄金模板 8 步（全局主轴）
1. 开篇炸点（危机/意外/反转）
2. 主角亮相（性格+能力+困境）
3. 目标确立（活下去/复仇/破案/相爱）
4. 连续小冲突（不断闯关）
5. 中期大反转（颠覆认知）
6. 人物成长（主角蜕变）
7. 最终高潮（决战/抉择/真相）
8. 结局闭环（情感+逻辑双满足）

## 冲突制造公式（全局通用）
想要 → 得不到 → 有人拦 → 只能拼 → 付出代价
