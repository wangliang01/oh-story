# 签约级标准与调教协议

## 什么是"签约级"（相对平庸的操作性定义）

签约 = 有人愿意为它付费/买单。判断依据不是"写得好"，而是"**有人非它不可**"。

达到签约级，至少要满足：
1. **独特卖点**：一句话能说清"它和同类不一样在哪"，且这个不一样是市场要的（不是自嗨的猎奇）。
2. **开头留存力**：长篇前三章 / 短篇开头 10% 内，读者产生"必须读下去"的理由。
3. **情绪峰值**：至少有一个场景能让目标读者情绪波动（爽/痛/甜/怕），且峰值被安排在读者最投入的位置。
4. **人物可共情**：主角的欲望读者能代入，缺陷读者能原谅，底牌读者会期待。
5. **节奏控制**：该快的地方快（冲突、反转），该慢的地方慢（情绪沉淀）。
6. **对标不输**：在同类已签约作品的共性基线上没有明显缺口，最好有 1 项超出。

## 平庸信号清单（命中 3 条以上 = 平庸）

- 卖点换个人名就能安到任何同类作品上
- 前三章没有不可替代的冲突（随便哪个故事都能这么开）
- 主角的欲望换成任何其他目标都不影响剧情
- 删掉任何一个配角/场景/设定，故事不受影响
- 情绪全靠形容词堆砌，没有靠情节制造的情绪
- 读者能准确预测每一步走向（无意外、无代价）
- 结尾只是"讲完了"，没有余味
- 作者想表达的（主题）和读者实际感受到的不一致

## 对标方法（子 Agent C 用）

- 同题材找 2~3 部已签约/高热度作品，提取"读者共性买单点"
- 逐项对照：本作品有没有 / 弱多少
- 找"超过基线"的点：那是签约筹码，写作时放大它
- 禁止用"文笔好/感情真挚"这类不可证伪的话当结论

## 对标库

### 现实情感（知乎盐选短篇）· 从 14 篇签约范文提取

**导语基线（硬规则，命不中 = 开头不合格）**：第一句必须是**画面 + 冲突**，禁止背景介绍开头。
- 炸弹型："去健身房接老婆，却看见她跟一个男人姿势暧昧。"（被绿后）
- 三句话危机型："高速上我开了定速巡航，可我发现刹车不管用了。"（生死高速）
- 异常细节型："我女朋友租了一个她绝对租不起的房子，还和房东眉来眼去。"（房租背后）

**叙述者人设基线**：现实情感的辨识度第一来源是**叙述者的性格与嘴**（克制蓄怒/幽默活泼/冷静幽默/自嘲打脸）。主角三要素里，"缺陷/底牌"在现实情感中要落实为"叙述者怎么说话、怎么行动"——换一个叙述者性格，故事就不成立，才算立住了。

**情绪峰值基线**：峰值前置且密集。生死高速第 5 段就出现"我爱你"；不写情绪词（我很怕/我很震惊），写身体反应与动作（"我喇叭不敢停""我愣住了""八月的天，我却像掉进了冰窟"）。

**节奏基线**：节极短（数字 1/2/3 分隔），每节一个推进；短句密集；对话推进剧情（对话里带信息、情绪、性格）。

**结尾基线**（二选一，必须有一句"定性/余味"的话）：
- 金句定性："坏人接受惩罚，贱人付出代价。"
- 反差余味：生死后的一句"嗯，真乖！"

**爽点结构**：现实情感的核心爽点 = 主角从被动（被绿/被骗/被欺）到主动反制的**绝地反杀**，反制必须建立在证据/谋划（冷算型）或语言杀伤上，不能靠运气。

### 悬疑（盐选短篇）· 从 12 篇签约范文提取

**开场基线（硬规则）**：第一段必须出现"说不通的东西"（异常细节或反常逻辑），禁止从解释世界观/背景开始。
- 异常物件型："扒死人衣服，却摸到……那手感很细腻，像在摸人的皮肤。竟还带有一丝温度"（极乐画卷）
- 反常即疑点型："每一步都能用「恰巧」和「无意中」来解释。就跟赶着去送死一样！"（巧合）
- 诡异事件型："家里的牲畜，一夜之间全被放干了血"（恶媳）

**悬疑感来源**：解释不通的巧合/细节，不是吓人；用"正常日常"包裹异常真相（活在真空里）。

**结构基线**：层层递进的揭秘结构，每节结尾留小钩（黑楼往事）；真相必须"比猜测更黑"（黑楼往事）或"太迟了"（翻案）。

**结尾基线**：真相必须回收全部钩子；**首尾呼应**——结尾重复开头的钩子句但语义翻转（巧合：开头"就跟赶着去送死一样！"，结尾同一句，读者此时才懂含义）。

**规则感基线**：奇幻/设定类用清晰的规则感增加可信度（我被天庭裁员了：神话体系+现代职场）。

**视角基线**：儿童视角的"不明白"反衬大人悲剧（牙仙子的真相）。

### 言情（盐选短篇）· 从 4 篇签约范文提取

**开场基线（硬规则）**：第一段就建立"不对的关系"（关系错位开局）：
- 身份错位："到了约定的地点，出现的却是我的上司任清雪"（女上司同居）
- 认知错位："她顿了顿，说我们是普通朋友"（失忆背叛）
- 选择错位（后悔感前置）："我拒绝了她……就为了这三千块，她差点毁了一辈子"（拒绝借钱）

**情绪基线**：遗憾/心动前置但克制——不写"我很爱她"，写一个动作（"我低下头，将她拉近"）；叙述者多为克制内敛型（海盐玛奇朵）。

**结构基线**：关系反转是核心爽点（权力反转/记忆与身份/错过与遗憾/婚姻价值觉醒），反转必须推翻读者开局的预期。

**结尾基线**：呼应开头的关系错位并修正落地——"从我的上司，变成我租来的女友。最终，成为了我的妻子"（女上司同居）；"南湖公园，你再陪我去一次，好不好？"（拒绝借钱：开放式余味+意象回收）。

## 调教回流协议（每次验证后必做）

1. 统计本次评审发现的**系统性缺口**（多个子 Agent 同时指出 = 系统性问题，不是个例）
2. 判断该缺口属于哪一层：卖点/人物/情节/世界观/评审标准
3. 写回对应 skill 的 references 下 notes 文件（追加条目，标注日期与来源作品）
4. 输出"校准日志"：新增了什么、下一版 skill 会怎么审
