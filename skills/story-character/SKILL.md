# story-character · 人物设计

读者记住的永远是人，不是剧情。人物立不住，情节再牛也白搭。

## 何时使用
- 用户要设计或完善人物
- story-bible.md 的"人物"节还是 draft，或人物节被评审标记为 ⚠️/❌

## 输入
- story-bible.md（卖点/基调优先参考，人物要服务于它们）

## 篇幅模式
- **短篇/微小说**：只做主角三要素（欲望/缺陷/底牌），外加**至多 1 个关键关系人物**（他/她承载主角的冲突与情感张力）。不设计三类配角，不设计完整反派——短篇里的"阻力"可以是环境、命运或一个对手，不需要动机/能力/底线的完整构造。三要素必须互相咬合：缺陷在开头就撞上冲突，底牌只在结尾引爆。
- **长篇**：按主流程执行（三类配角 + 反派三逻辑）。
- **中篇**：主角三要素 + 1~2 个配角（其中可含 1 个阻碍型）+ 轻量反派（有动机、有能力即可，底线可省略）。

## 流程

### 第 1 步 · 主角三要素：欲望、缺陷、底牌
逐项访谈，每项最多 2 问，附示例：
- **欲望（目标）**：主角到底想要什么？复仇/爱情/活下去/真相/权力/救赎……目标越清晰故事越有劲。问：他想要什么，具体到"不做会死/不甘心"的程度。
- **缺陷（弱点）**：懦弱、偏激、社恐、恋爱脑、过度理性、创伤后遗症……完美主角最无聊，缺陷制造冲突，冲突推动剧情。问：他身上哪个缺点会在关键时刻害他？
- **底牌（能力/优势）**：智商、体能、观察力、心理洞察、系统、人脉、执念……没有底牌，主角一路被虐，读者弃文。问：凭什么最后是他赢？

示例（可直接展示给用户）：主角 = 欲望（查明十年前姐姐的死亡真相）+ 缺陷（过度理性，无法信任任何人）+ 底牌（过目不忘的记忆力）。

### 第 2 步 · 三类配角
每类至少设计 1 个，问清楚"他/她在剧情里加速了什么"：
- **助攻型**：帮主角、给信息、推关系 → 问：他怎么推动主角前进？
- **阻碍型**：制造冲突、设难关、逼主角成长 → 问：他卡住主角的哪条路？
- **镜像型**：与主角相似但选择不同，反衬主题 → 问：他与主角的分岔点在哪？

避免"工具人"：每个配角写清 类型｜作用｜与主角关系。好配角让故事厚度翻倍，烂配角只会注水。

### 第 3 步 · 反派三逻辑
- **有动机**（原生家庭/信仰/利益/创伤）——他为什么这样？
- **有能力**（智商、资源、手段在线）——他凭什么构成威胁？
- **有底线**（哪怕是扭曲的底线）——他绝对不做什么？

反派越立体，主角越出彩，小说越高级。示例：动机（幼年全家被主角父亲所害）+ 能力（掌控整个地下情报网）+ 底线（绝不伤害孩子，哪怕复仇）。

## 平台适配（男频）
- **盐选**：主角 = 普通人 + 强性格（嘴/谋略/隐忍），底牌是性格与判断力，不靠超能力（对标：房租背后/被绿后）。
- **番茄**：主角 = 憋屈处境 + 金手指/系统，底牌即金手指，欲望 = 变强/复仇/逆袭；金手指必须有代价或限制（防止无脑爽）。

## 命名规则（一次校准：用户评审反馈）
- 禁寓意名（陈默/沉默、李强/自强）——名字不是性格注脚，一看就是编的。
- 按出生年代配名：60后（国梁/永年/宏达/德贵）、70后（立诚/永刚/建军）、80后（磊/鹏/宇/杰/浩）、90后（浩然/子豪/嘉伟）。
- 允许真实感的"不完美"：外号、小名、重名、辈分字。
- 自查：把名字遮住，能否从名字猜出性格？能 = 换掉。

## 输出
story-bible.md"人物"节，更新 status。

## 完成标准
主角三要素齐全且互相咬合（缺陷能制造冲突、底牌能支撑欲望的实现路径）；配角各标类型与作用；反派三逻辑齐备。全部无【待定】。

**底牌必用规则（一次校准）**：底牌不能只是"设定"，必须被用进**至少一个关键情节转折**（主角凭这个能力发现/破解了别人发现不了的东西）。设计完成后自查：把底牌从故事里拿掉，剧情还成立吗？成立 = 底牌没立住，重设计。

**叙述者人设规则（现实情感/言情专项，一次校准）**：写现实情感、言情等第一人称短篇时，主角的"缺陷/底牌"必须落实为**叙述者怎么说话、怎么行动**（克制蓄怒=闷声取证；幽默活泼=短句带节奏；自嘲=开头嚣张结尾认栽；言情克制内敛=情绪全压进动作"我低下头，将她拉近"）。自查：换一个叙述者性格，故事还成立吗？成立 = 人设没立住。叙述者的嘴是第一辨识度，比情节更难被替代。
