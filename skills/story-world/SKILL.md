# story-world · 世界观与细节

真实感不是靠大场面，是靠小细节。本 skill 负责把"设定"变得自洽、可写、有代入感。

## 何时使用
- 用户要设计/完善世界观
- "世界观"节是 draft 或评审不通过

## 输入
- story-bible.md（世界观要服务于人物与冲突：力量体系支撑升级爽点，时代限制约束人物行为）

## 篇幅模式
- **短篇/微小说（最小必要设定）**：只写 2~3 条**会被写进具体场景**的设定，每一条都能直接撑起一个情节转折；不设计力量体系/社会等级等完整框架。多余设定一律砍掉——短篇里每多一个设定就多一分读者负担。
- **长篇**：按主流程执行（三问 + 8~15 条细节 + 自洽性检查）。
- **中篇**：三问精简版 + 5~8 条细节。

## 流程

### 第 1 步 · 世界观三问
逐问访谈，附示例：
1. **世界规则是什么？** 力量体系、社会等级、法律、禁忌。
   - 示例：修仙世界——灵气浓度决定修为上限；凡人不得窥探宗门内务。
2. **力量体系能不能自洽？** 别后期随便开挂。升级路径、代价、上限都得说清。
   - 示例：灵力来自吸收灵石，瓶颈期需顿悟；强行突破会反噬。
3. **时代背景对人物有什么限制？** 古风不能乱说话，现实不能超自然。
   - 示例：古代背景——女子不能抛头露面 → 主角复仇只能借他人之手。

### 第 2 步 · 细节清单
按"能被写进具体场景"的标准，产出 8~15 条细节：
- 衣着、食物、口音、习惯
- 建筑、气候、节日、礼仪
- 职业、阶层、潜规则、暗线

每条细节问一句：**它会在哪个场景里被用到？** 用不上的细节不要写。

### 第 3 步 · 自洽性检查
把世界观与卖点、人物、情节对照：
- 力量体系能否支撑主角的"底牌"和升级路线？
- 社会规则是否制造了主角的核心阻碍（冲突）？
- 有没有明显漏洞？（后期开挂点提前埋好伏笔）

## 平台适配
- **番茄长篇**：世界观必须支撑长期升级——境界/等级/资源体系明确（升级即爽点），大世界 + 清晰势力格局。
- **盐选短篇**：最小必要设定（2~3 条），不建体系。

## 输出
story-bible.md"世界观"节，更新 status。

## 完成标准
三问全部有明确答案；细节清单每条都绑定一个具体场景；自洽性检查无未解释的开挂点。无【待定】。

**机械闭环规则（一次校准）**：设定里的每一条规则，都必须与主角的**关键行为**机械绑定——主角做了 X，规则必然响应 Y（如"交出最愧疚的声音 → 亡魂解脱"）。规则写完后自查一遍：结尾主角的关键动作，是否直接触发某条已声明的规则？触发不了 = 结尾不闭环，改规则或改动作。
