# story-validate · 评审与救场

把"感觉不对"变成"哪里不对、怎么改"。本 skill 是构思套件的质检环节（原名 story-review，因与 oh-story 的 story-review 重名而改名 story-validate）。

## 何时使用
- 用户有 story-bible.md 或已有草稿，想检查质量
- 用户写崩了（人设崩、看不懂、没感觉、想弃文）来救场
- 用户要求"再检查一遍"

## 输入
- story-bible.md（先读头部**篇幅**字段，按对应模式选择检查清单）；若用户带草稿/片段，一并读取

## 篇幅模式
- **短篇/微小说（短篇专项清单）**：① 开头前 3 句是否抓住人（首句即钩子）——**前 500 字必须出现事件/异常**（一次校准：短篇开头靠氛围铺垫而非事件 = 弃文点，写作时先事件后氛围）；② 结尾是否有冲击力或余韵（不是"剧情讲完了"而是"情绪落地了"）；③ 信息密度——每一段都在推进剧情/人物/情绪，无废段；④ 单弧光是否完整（有没有偷偷塞副线或多余设定）；⑤ 篇幅是否配得上内容（该 3000 字写完的有没有拖到 8000）。
  - **现实情感专项（一次校准，源自 14 篇签约范文）**：⑥ 第一句是不是画面+冲突（背景介绍开头 = 不合格）；⑦ 叙述者人设辨识度——换一种性格这个故事还成立吗；⑧ 情绪峰值是否前置（1/5 处）；⑨ 是否写情绪词代替行为（"我很怕" = 不合格，应为"我喇叭不敢停"）；⑩ 结尾是否有金句/余味收尾。
  - **悬疑专项（一次校准，源自 12 篇签约范文）**：⑪ 第一段是否出现"说不通的东西"（没有 = 不合格）；⑫ 每节结尾是否有小钩；⑬ 结尾是否回收全部钩子（有没回收的 = 不合格）；⑭ 真相是否"比猜测更黑"（平于猜测 = 平庸）；⑮ 是否用了首尾呼应（可选但加分）。
  - **悬疑专项补充（2026-08-14 首稿评审校准）**：⑯ 导语之后第一节正文也必须是异常场景/冲突，**禁止生活流铺垫**（交班/起床/上班流水账 = 弃文点，首稿《13块5》第 1 节踩坑后压缩）；⑰ 中段"查案/信息收集"段必须带情绪推进（纯信息段 = 掉追读，交警队/调查戏每段至少一个情绪点）。
  - **言情专项（一次校准，源自 4 篇签约范文）**：⑯ 第一段是否建立关系错位（没有 = 不合格）；⑰ 核心是否关系反转（只有虐/甜没有反转 = 平庸）；⑱ 情绪是否克制（直写"我很爱她" = 不合格）；⑲ 结尾是否呼应开头错位并落地。
- **长篇**：按主流程执行（黄金模板 8 步 + 八坑）。
- **中篇**：黄金模板为主，叠加短篇专项的 ①②③ 条。

## 平台专项检查（一次校准：盐选调查）
评审时先读 story-bible 头部**平台与篇幅**字段，加载 `story-platform/references/<平台>.md`（解析顺序见 story-conception「参考资料解析顺序」）后逐项执行：
- **情绪出口**：全篇是否有至少一个情绪释放点（爽/解气/暖/释然）？**全程压抑 = 不合格**（《岳母的存折》反例）。
- **具象度**：抽象词（很/非常/很久/大城市）是否泛滥？每章是否有 2~3 个具体细节锚点（金额/地名/年份/品牌/职业黑话）？
- **格式（盐选）**：「」引号？数字分节？无章节标题？单段 ≤3 行？讲话单独分段？关键反转句独立成段？导语独立且不加标点收尾？
- **字数档位**：盐选短篇按 **12k+** 写（官方下限 8k，但市场默认 12k~15k，<12k 会被当低字；12k~15k 目标，上不封顶至 3w）；番茄每章 2000~3000 字。
- **字数缺口处理（2026-08-14 grilling 校准）**：差字数时**禁止找补**（按字数缺口在段落里见缝插针 = 注水，而且塞进去的多半正是盐选明令禁止的环境描写/心理独白）。先**诊断缺口类型**再选工具：① 骨架规划的节没写全 = 缺拍子 → 加情节；② 骨架全交付但每节写薄 = 密度缺口 → 补全/具象化；③ 没缺拍子也没写薄 = 没缺口 → 接受压线。**加情节三问**（全答得出才允许加）：这条线服务哪个已知缺口？在哪个位置回收（闭环稿新线必须回收干净，收不干净 = 欠账，比注水更糟）？删掉它故事塌不塌（塌 = 合格；不塌 = 平庸信号）？所有新增内容统一过**删除测试**：删掉后读者体验不变 = 注水，不合格。
- **平台节奏**：盐选 = 每节 500~800 字反转单元 / 三章必反转；番茄 = 黄金三章 / 每章结尾钩子。
- **市场匹配（2026-08-14 重核）**：题材与平台是否匹配（查 `story-platform/references/market-signals.md`）？如硬核刑侦投番茄（有天花板）、规则怪谈/民俗投盐选（男频机会）未按盐选节奏、世情写盐选却按番茄节奏（即时爽 vs 余味）→ 退回改平台或改节奏。
- **改编性硬门槛（2026-08-14 用户确认升级）**：盐言短篇必过四查——场景化（能演）/台词化（能说）/强画面（能看）/反转可视化（能拍）？**任一项不过 = 不合格退回**（短剧=最强变现通道，版权收入 +139%；番茄连载不适用此条，适用黄金三章钩子）。

## 一眼假检查（一次校准：用户评审反馈）
评审必做，命中任一 = 不合格退回：
- **命名**：是否有寓意名/脸谱名（陈默/沉默、赵建国式）？名字能否猜出性格？（规则见 story-character 命名规则）
- **专业流程**：法律/举报/行业流程是否真实？如私营企业腐败 = 公安经侦（职务侵占/挪用资金，立案标准 3 万+），不是纪委；不确定必须查证。
- **数字工整度**：金额/日期是否全为整数？真实账目带零头（7183.5 ≠ 7200）。
- **对白冗余度**：是否每句对话都在推进情节？真实对话有寒暄、有答非所问、有没说出口的话。
- **对白标签纪律**（一次校准 2026-08-14）：第一人称禁「我说：」；「他说：」能少则少（首次/转述/多人除外），优先动作/神态替代（"大刚把车钥匙扔给我：「…」"）。连续 3 个以上标签 = 退回重写。
- **生活毛边**：是否有非主题细节（社保/房贷/年龄门槛/同事闲话）？事件是否过于完美闭环？每节至少一个毛边（见 story-platform/references/craft.md）。
- **人性复杂**：人物是否只做"有利于剧情"的选择？有没有犹豫、反悔、吃亏？
- **母题同质化**：反杀/反转手段是否老套（打一顿/朋友圈曝光）？对照 story-platform/references/tropes.md 的同质化警报逐条查。
- **结尾类型**：是否平淡长收（"这件事让我明白了很多道理"式）？短句/称呼收尾是常态（35~47%）。

## 模式 A · 评审（有完整圣经或大纲时）
1. 逐项对照**黄金模板 8 步**：开篇炸点 / 主角亮相 / 目标确立 / 连续小冲突 / 中期大反转 / 人物成长 / 最终高潮 / 结局闭环。每步给出 ✅ 通过 / ⚠️ 薄弱 / ❌ 缺失 + 一句理由。
2. 逐项排查**八坑**：① 无核心目标→流水账 ② 人物前后矛盾 ③ 情节全靠巧合 ④ 只堆情节无情绪 ⑤ 节奏忽快忽慢 ⑥ 伏笔满天飞不收 ⑦ 沉迷自嗨不管读者 ⑧ 总想大格局、小剧情都写不明白。对命中的坑给出**具体修订建议**（结合该用户自己的卖点/人物/情节，不空谈）。
3. 列出全部 `【待定·可改】`——这是必须补齐项。
4. 输出评审报告，写入"评审记录"节；给出"下一位该修什么"的排序。

## 模式 B · 救场（写崩了）
1. 先让用户描述症状：写到哪里崩的？崩在人物、逻辑、节奏还是读者反馈？
2. 对照八坑**定位**（最多问 3 个定位问题，不要审问用户）。
3. 给定向修复方案，格式：**问题 → 原因 → 具体改法（给出可抄的改写示例）→ 防止再犯的规则**。
4. 若根因在某一节没构思好（如人设前后矛盾 → 欲望/缺陷没立住），联动对应子 skill 补那节，再回来评审。

## 完成标准
- 评审模式：八步全 ✅ 或明确列出遗留项与优先级；八坑无 ❌。
- 救场模式：定位到具体坑、给出可执行的改法，且用户认可。
