# 题材基线库（盐选·数据背书）

> 来源：analyze-corpus.py 对 7028 篇语料的统计（2026-08-14）+ 定向精读。

## 全题材通用数据（写任何题材前先看）

> 全量语料交叉验证（盐神 1339 篇 + 搬运工 7028 篇 = 8367 篇，2026-08-14 重跑），导语/结尾/分节结论跨语料一致。

| 指标 | 数据 | 转化规则 |
|---|---|---|
| 导语长度 | 均值 26 / 中位 21 / P75 30 字 | **导语黄金区间 15~28 字**。超 30 字 = 太啰嗦；短于 10 字 = 悬念不足 |
| 分节数 | 中位 10 节 | 知乎问答短回答按 **9~11 节** 规划（本次语料中位 10）；盐选签约完整短篇仍按 **15~21 节**（签约范文实测中位 18） |
| 结尾类型 | 短句/称呼 49% ｜ 平淡 28% ｜ 对话 11% ｜ 哲思/展望 5% | **短句收尾是常态**（"小祖宗。""嗯，真乖！"）；狠话金句是加分项不是必选项 |
| 题材热度 | 家庭/亲情 32% ｜ 言情/情感 20% ｜ 其他 16% ｜ 现实情感 11% | 家庭+情感类是盐选基本盘；悬疑是稳定第二梯队 |

## 一、家庭/亲情（32%，盐选最大基本盘）

**导语公式**：极端家庭事件 + 人物关系 + 数字/时间（"半年前，妈妈跪在地上求我为继妹捐一颗肾"）
**开头模式**：直接进事件，不介绍家庭背景；反常细节（"侄子九岁了，拿钉子在汽车上画画，车主要求赔偿"）
**反转母题**：偏心真相 / 牺牲被看见 / 恶人伪装 / 迟来的理解 / 血缘 vs 养育
**人物原型**：被牺牲的长子长女、偏心的父母、恶毒继亲、懂事的孩子
**情绪**：虐 → 暖（主流）或 虐 → 狠（反杀）
**易踩坑**：家庭题材最容易写成"讲道理"，必须落在一个具体事件上
**对标导语**："我爸是毒枭，我妈是卧底。"（10 字短促狠）

## 二、言情/情感（20%）

**导语公式**：关系错位/背叛 + 时间点（"羊水早破那天，老公在帮初恋庆贺生日"）
**开头模式**：第一段建立"不对的关系"；对话带火药
**反转母题**：误会澄清 / 前任回归 / 身份反转 / 迟来的告白
**情绪**：甜虐交织；7:2:1 起伏
**易踩坑**：甜过头 = 腻；虐过头 = 读者跑；必须每 2~3 节一个感情推进
**对标导语**："大一开学前，我加了新生群。"（15 字，留白式悬念）

## 三、悬疑/犯罪（6%）

**导语公式**：异常事件 + 时间/地点（"我醒来的时候，周围一片黑暗"；"八年前，学弟在工地上杀了一个工友，杀人前，他给警察打了电话"）
**开头模式**：职业视角切入（法医/刑警/律师/记者），专业细节即真实感
**反转母题**：真相比猜测更黑 / 完美犯罪破绽 / 受害人是加害者 / 迟到的正义
**情绪**：冷、紧、层层逼近；结尾"太迟了"或"昭雪"
**易踩坑**：流程错误（警察办案/举报渠道必须真实，不确定查证）；逻辑漏洞
**对标导语**："有，「香港油炸人肉案」。"（8 字，回答式开头）

## 四、现实情感（11%）

**导语公式**：数字/年龄反差 + 极端情境 + 反杀预告（"二十七岁的表妹嫁给了七十二岁的老头，在婚礼上她大胆的和前男友在房间里约会，却不知道他们的这一幕，已经被我找人投屏到了舞台的大屏幕上"）
**开头模式**：憋屈事件直接开场；叙述者性格立住（嘴/谋略）
**反转母题**：绝地反杀 / 记账本式证据 / 投屏式公开处刑 / 因果报应
**情绪**：憋屈 → 解气；情绪出口必须强
**易踩坑**：同质化（被绿反杀写烂了，必须加新机制：投屏/录音/账本/监控）
**对标导语**："我高考 605，却被男友窜改志愿，上了二本。"（18 字，数字+受害）

## 五、都市/职场（4%，男频主战场）

> 语料占比 4% 不代表平台热度低——都市职场是知乎问答语境下分类偏保守的品类，平台口径现实情感（含婚姻/职场）占 28%（见 market-signals.md）。

**导语公式**：职场憋屈/阴谋 + 短句（"公司的绿茶请大家吃饭，选了一家高档餐厅"）
**开头模式**：饭局/办公室/裁员现场；职场黑话具象化
**反转母题**：背锅真相 / 裁员反杀 / 职场恶人现形 / 老实人的底牌
**情绪**：憋屈 → 解气；节奏快
**易踩坑**：职场细节失真（KPI/期权/社保/裁员流程）；人物脸谱化
**对标导语**："我高考 605……" 类数字受害式；"我曾经有过一个绰号，叫「大蛇」。"（悬念型）

## 六、校园/灵异（快速参考）

- **校园（7%）**：暗恋/成长/反欺凌；导语常用时间+事件（"大一开学前，我加了新生群"）；青春感靠细节不靠口号
- **灵异/玄幻（5%）**：禁忌：灵异可悬疑不可装神弄鬼；玄幻要规则感（力量体系自洽）

## 使用方式
- **story-premise 生成卖点前**：查本库对应题材，套导语公式 + 查"易踩坑"避免撞车
- **story-qualify Agent C 对标时**：本库是题材基线的第一来源，范文目录（用户 examples/ 或范文库）是第二来源

## 专项：出租车夜班灵异（2026-08-14 定向学习，男频盐言主攻题材）

> 子集 1731 篇（出租车∩灵异，盐神+搬运工）分析 + 精读结论。**关键发现：2023 语料库无成型的出租车夜班灵异完整故事范本（只有零散段子）→ 题材未被写烂 = 蓝海，结构对标用签约悬疑基线（story-qualify/reference.md）+ 规则怪谈结构。**

**导语公式（规则怪谈式优先）**：时间点 + 反常物件/计价规则 + 悬念（"凌晨两点，计价器跳了，后座没人"；"开了八年夜班出租，我从不拉凌晨三点的客"）
**开头模式**：夜班场景直接进（交班/上客/计价器异常），禁止背景介绍；司机口头禅/黑话立声音（"干我们这行的""跑夜车的""我跟你说"）
**反转母题**：后座没人但计价器跳（超自然钩子）→ 合理化（活人每晚打车同路）→ 真相比猜测更黑（乘客的执念 vs 司机自己的执念）→ 首尾呼应（规则句最后一句翻转含义）
**细节锚点**：计价器跳字/空车牌/份子钱/夜班黑话/凌晨路况（洒水车/环卫工/夜宵摊）/乘客细节（鞋/气味/找零）
**情绪弧**：好奇 → 发毛 → 追查 → 真相更黑 → 释然/愧疚（7:2:1，必须有情绪出口）
**易踩坑**：① 装神弄鬼直写（盐选禁，全程不给超自然明确解释，留细思极恐空间）② 结局只吓人没落点（必须落回人情/人性）③ 行业细节失真（计价/份子钱模糊处理即可，不硬编）
**对标导语**："凌晨两点，计价器跳了，后座没人"（15 字，规则怪谈式）
