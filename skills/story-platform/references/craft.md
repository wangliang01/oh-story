# 技法库（盐选·精读提炼）

> 从 8382 篇语料 + 用户 30 篇签约范文精读（含《范文分类索引》解构）中提炼的可执行技法。

## 一、中段细节密度（撑住 8k~3w 的关键）

每段三层：**信息 + 情绪 + 吐槽**。缺一层 = 这段可以删。
- 信息：剧情推进（谁做了什么/发生了什么）
- 情绪：叙述者的态度（心疼/解气/无语）
- 吐槽：生活噪音（猫、快递、找零、菜单、A货）

**实操**：写完一段自查——这段只有信息没有吐槽？加一句生活噪音。只有情绪没有信息？砍半。

## 二、叙述者声音塑造（辨识度第一来源）

声音 = 方言 + 口头禅 + 吐槽 + 视角偏见。
- 口头禅例：司机"我跟你说""干我们这行的"；东北腔"OJBK""吭哧瘪肚"
- 视角偏见：叙述者必须有"偏心"——对某些人刻薄、对某些人袒护
- 自查：把口头禅全部删掉，故事还剩辨识度吗？没有 = 声音没立住。

### 对白标签纪律（一次校准：用户评审反馈 2026-08-14）
第一人称对话的铁律——**读者就是我**，一切标签都是出戏的元叙述：
- **禁「我说：」**：我说话不需要声明，直接上「内容」即可。
- **「他说：」能少则少**：双人对话轮换靠换行+内容区分；只在首次引入说话人、转述他人原话、多人混谈时才保留。
- **优先用动作/神态/场景替代标签**："大刚把车钥匙扔给我：「昨晚前杠蹭了一下」"（动作带出说话人）优于"大刚说：「…」"。
- **人名/称呼+说：可保留**：交警说：「…」、老太太说：「…」——配角首次出场必须交代说话人，轮换后删。
- **自查**：数一段对话里的「X说：」——第一人称对话中连续 3 个以上标签 = 叙述腔超标，动手删。

## 三、导语（15~25 字黄金区间）

- 数字/年龄反差（27 嫁 72、高考 605 被改志愿）
- 极端事件（妈妈跪下求捐肾、羊水早破那天老公在庆生）
- 悬念/误导（我参观我自己的家、结果那头报了我的名字）
- 独立于正文、不加标点、具象化禁抽象

## 四、结尾类型学（短句收尾是常态，占 35%）

| 类型 | 例 | 适用 |
|---|---|---|
| 短句/称呼 | "小祖宗。""嗯，真乖！" | 万能，最盐选 |
| 狠话/因果 | "重婚罪可是要坐牢的" | 反杀爽文 |
| 意象 | "发丝交缠，他说：青青，我来娶你了" | 虐/暖 |
| 哲思/展望 | "我们总能到达彼岸" | 重生/成长 |
| 对话 | 最后一句是人物的话 | 万能 |

禁止：平淡长收（"这件事让我明白了很多道理"式）。

## 四·五、数字双关/意象呼应（2026-08-14 首稿评审校准）

同一数字/物件在不同语境出现两次 = 记忆点，也是主题的暗扣。例（《13块5》）："3块5"既是车费差额、又是小雨辣条赊账——两笔 3.5 在账本里同框，"账要清楚"主题闭环；红笔写的 13.5 从"记账习惯"到"儿子还钱"全程一致。
- 用法：核心数字/物件设定一次 → 中途重复出现（变奏）→ 结尾回收变义（首尾呼应）
- 自查：故事里有没有一个可以"二次出现"的数字/物件？没有 = 缺记忆点。
- 金额动作方向自查（案例《13块5》首稿）：数字设计后必须核对"钱/找零/补钱/欠账"的方向——给的钱不够车费，动作只能是"补钱/差钱"，写"找零"= 逻辑 bug（10 块坐 13.5 的活，司机不可能找零）；反之给多了才能找零。方向错了 = 读者一眼出戏。

## 五、毛边清单（真实感 = 生活噪音）

每节至少一个非主题细节：
- 物：猫、快递、A货包、找零、护手霜、欧米茄表、烤红薯摊
- 动作：抹座套、挑鱼刺、数零钱、递烟
- 数字带零头：7183.5、28463.7、"就五百多"
- 规则：细节必须"用得上但没明说"——不能为细节而细节

## 六、反转密度（每 2~3 节一个）

- 反转 = 读者预期的推翻，不是新信息
- 导语就在泄底（导语已经说了核心反转，正文是"怎么走到那一步"）
- 每节结尾留小钩（下一节的第一个画面）

## 七、职业/流程真实感

- 职业细节：行话、工具、日常（计价器/空车牌/份子钱；法医/卷宗/尸检报告）
- 法律/举报流程：不确定必须查证（私企腐败=公安经侦，纪委只管公职人员；立案标准；安全生产=应急管理部门）
- 自查：把这个职业换成"普通人"，细节还有信息量吗？有 = 职业视角成立。

## 八、情绪曲线（7:2:1 起伏）

- 主情绪:次情绪:反转情绪 ≈ 7:2:1
- 必须有情绪出口（爽/解气/暖/释然），禁全程压抑
- 每 500~800 字一个情绪点；憋屈铺垫不超过连续 2 节

## 九、叙述者性格类型学（30 篇签约范文实测）

写主角前先选型，声音和行动都由型驱动。同一题材换型 = 完全不同的文（如冷算 vs 爽快）。

| 型 | 特征 | 代表作 |
|---|---|---|
| 克制蓄怒型 | 不发一声，闷着劲取证，爆发在最后一刻 | 房租背后 |
| 幽默活泼型 | 用"呸/妈的"带节奏，语速快短句密 | 女友劈腿老毕登后 |
| 冷静幽默型 | 自嘲不露愤怒，借力打力 | 被绿后帮老婆双宿双飞 |
| 憋着不说型 | 傲气外冷内火，城府深，反制留最后 | 夜引幽·白月光 |
| 自尊克制型 | 不出丑不求饶，短对白杀伤力强 | 床前白月光 |
| 硬汉型 | 话少行动多，沉默的爱 | 破事 |
| 冷静紧张型 | 生死间感情才说出口，身体反应写恐惧 | 生死高速 |
| 职业冷静→良知驱动 | 先职业视角冷观察，被真相逼出良知 | 车轮上的眼泪 |
| 内疚自省型 | 不美化自己，承认自己是共谋 | 沉默是罪恶的帮凶 |
| 自嘲幽默型 | 荒诞视角（鬼魂），死后才能说实话 | 死亡之后 |
| 平静隐忍型 | 痛藏得最深，实体意象承载情感 | 一次终生难忘的公路旅行 |
| 内省型 | 有距离感，像在讲别人的故事 | 童年的画 |
| 富二代自嘲型 | 开头嚣张结尾被打脸，镜子式配角 | 我的小妍 |
| 克制内敛型 | 话少情真，遗憾藏在细节 | 拒绝借钱给邻家姐姐 |
| 困惑脆弱型 | 失忆/身份认同，真相一层层剥 | 失忆背叛 |
| 自以为是→落地型 | 开头自信满满，结局悔悟反转 | 精彩生活从离开老婆开始 |

**选型规则**：① 先定基调（冷/热/痛/爽）再选型；② 型决定口头禅与行动方式，不单独设计性格；③ 同题材换型即换文（冷算型 vs 爽快型是两篇完全不同的文章）。

## 十、情绪弧模板（签约范文的情绪推进链）

每篇先定情绪弧，再往链上挂情节——情节为情绪服务，不是反过来。

| 题材 | 情绪弧模板 |
|---|---|
| 出轨冷算 | 震惊→不敢置信→蓄怒→冷算取证→反击 |
| 出轨爽快 | 如遭雷击→愤怒→冷静谋划→绝地反杀 |
| 幽默收拾 | 猝不及防→冷算谋划→幽默式收拾 |
| 生死极限 | 极度恐惧→镇定求生→后视镜里的爱→感恩 |
| 道德沉沦 | 中年空洞→羞耻→内疚→良知反弹→救赎 |
| 悬疑调查 | 调查→发现→真相比猜测更黑 |
| 日常藏奸 | 表面正常→内部腐烂→最后一刻才看清 |
| 亲情暗战 | 亲情表面→真实利用→被牺牲才发现 |
| 儿童视角 | 天真不明白→大人秘密→真相是保护 |
| 翻案 | 旧案被推翻→正义迟到→代价已付清 |
| 丧失思念 | 悲伤压着不说→孤独旅程→和解 |
| 童年创伤 | 童年疑惑→悲伤→成年回望→和解 |
| 错过遗憾 | 自保→遗憾→情感觉醒 |
| 关系反转 | 不情愿→日常相处→关系反转 |
| 婚姻觉醒 | 期待自由→真相是错觉→悔悟 |

**使用**：选题材 → 查情绪弧模板 → 按链设计每节的情绪推进 → 再写情节。链上每跳一次情绪，就是一次情节转折。

## 使用方式
- story-plot 写作时对照：中段密度/导语/反转/情绪曲线/情绪弧模板
- story-premise 定主角时对照：叙述者性格类型学（选型）
- story-review 评审时对照：结尾类型/毛边/声音/流程真实感/性格与情绪弧是否成立
